Controls Reference

Touch Controls:

  • Single tap → Pause / Resume
  • Double‑tap left → Rewind 50 words
  • Double‑tap right → Skip 50 words
  • Swipe up/down from bottom → Adjust speed
  • Tap top‑left corner → Exit Fullscreen

Keyboard Controls:

  • Space → Pause / Resume
  • Left Arrow → Rewind 50 words
  • Right Arrow → Skip 50 words
  • H → Toggle UI
  • ESC → Exit Fullscreen
  • Scroll wheel → Adjust speed
