Tap Controls:

  • Single tap → Pause / Resume
  • Double‑tap left → Rewind 50 words

  • Swipe up/down from bottom → Adjust speed (mobile)

Keyboard Controls:

  • Space → Pause / Resume
  • Left Arrow → Rewind 50 words
  • Right Arrow → Skip 50 words
  • H → Toggle UI
  • ESC → Exit Fullscreen
  • Scroll (wheel) → Adjust speed (desktop)
